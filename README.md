# Sisters’ Touch : Manicure & Pédicure

Luxury beauty salon website built with React, Tailwind CSS and Framer Motion.

## Getting Started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the development server

   ```bash
   npm run dev
   ```

3. Build for production

   ```bash
   npm run build
   ```

## Features

- Sticky transparent navigation
- Hero section with premium beauty styling
- Services, pricing, gallery, testimonials
- Online booking form
- Contact section with Google Maps embed
- Floating WhatsApp and Facebook buttons
- Responsive mobile-first layout
